# Экосистема на решётке (вариант 41)

Симуляция экосистемы: решётка с растительностью, травоядными и хищниками.
Поколение считается одномоментно; все случайные величины берутся из одного
генератора с задаваемым зерном.

## Стек

- Java 17
- Maven
- JUnit 5

## Сборка и запуск

```bash
mvn clean package
java -jar target/ecosystem-1.0-SNAPSHOT.jar
