# Экосистема на решётке (вариант 41)

Симуляция экосистемы: решётка с растительностью, травоядными и хищниками.
Главное правило: **поколение считается одномоментно**, порядок обхода клеток не влияет на результат.

## Стек
- Java 17
- Maven
- JUnit 5

## Правила симуляции

1. **Рост травы.** Трава на клетке растет на `grassGrowthPerTick` за поколение, но не превышает `grassMaxLevel`.
2. **Питание.**
   - Травоядные едят траву на своей клетке (до 3 единиц).
   - Хищники едят травоядных на соседних клетках (4 направления) и получают энергию.
3. **Движение.** Животные могут переместиться на свободную соседнюю клетку (с вероятностью 50%).
4. **Размножение.** Если энергия выше порога, создается потомок.
5. **Смерть.** Животное умирает, если энергия падает до 0 (голод) или возраст превышает максимальный.

Все числовые параметры задаются через `SimulationConfig`.
